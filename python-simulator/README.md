# Tradyn Simulator — original Python engine

The Algorithmic Stock Market Simulator as first built in Python (NumPy + Pandas): rule-based traders, the
10-stage market loop, market events, analysis and the Experiment Lab. It runs in the terminal, offline.
The Tradyn web app uses a TypeScript port of this engine (`../src/lib/simulator`) with the same rules.

```bash
cd python-simulator
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python simulate.py                                # one run with a market shock at 45%
python simulate.py --steps 800 --seed 7 --export out/
python -m tradyn.experiments --scenario shock --runs 30
python -m tradyn.experiments --sweep
python -m unittest discover -s tests              # 17 tests
```

```
Demand Ratio = (Buy − Sell) / (Buy + Sell + 1)
New Price    = Old Price × (1 + Sensitivity × Demand Ratio)      (±5% per step, never below the minimum)
```

Simulation only — every price is generated by the simulated traders, never real market data.
